# 15. Security, Privacy & Compliance

## Security Architecture
- Password hashing using PBKDF2/bcrypt.
- Cryptographic JWT bearer tokens with expiration.
- SQL injection immunity via SQLAlchemy parameterized ORM queries.
- Cross-Origin Resource Sharing (CORS) header configuration.

## Privacy & Audit Logging
- Sensitive welfare case access is restricted and audited.
- Anonymous donation flags obscure donor names on public pages.
